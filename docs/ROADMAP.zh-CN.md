# 学习路线与后续工作

[English](ROADMAP.md) · [开始学习](GETTING_STARTED.zh-CN.md) · [参与贡献](../CONTRIBUTING.md)

当前包含 63 节课：公用基础 4、搜索 19、广告 23、推荐 17。搜索 S01–S18 与广告 A01–A18 的**核心教学目标**都有可运行内容，其中部分目标有意使用构造样例。这里列的是下一层深入工作，不是缺失的导航入口，也不代表当前已有生产级完整能力。

## 已有基础

- 四条归属清楚的路径，包含先修、来源与证据标记。
- 中英教学文字与英文配套 Notebook，保留同一套代码和历史输出。
- 安装前可只读课程，需要运行时再进入 Jupyter、按需准备数据。
- 真实推荐、搜索与 CTR 实验；教学训练隔离，负结果保留。
- 来源清单、逐单元完成记录与复现协议。

补齐之前的审计保留为历史。当前交付证据见[搜索完成记录](SEARCH_CURRICULUM_COMPLETION.json)和[广告完成记录](ADS_CURRICULUM_COMPLETION.json)；它们记录教学验收，不代表完整课程或论文配方全部复现。

## 优先值得深入的实验

下表是建议方向，不是排期承诺。每次贡献先明确学习问题和可达成的评估，再选择实现。

| 方向 | 现状与限制 | 下一步交付 | 验收证据 |
|---|---|---|---|
| 搜索 · 查询理解 | 36–39 使用字典切词和意图 / 改写规则 | 在许可清楚的数据上训练小型意图或改写模型 | 按查询或会话隔离切分；规则基线；歧义 / 拒识例；同时评估检索误差 |
| 搜索 · 语义召回 | 27 使用冻结 MiniLM；42 训练小型交叉编码器 | 有预算约束的双塔训练对照 | 固定候选与切分；损失和向量更新证据；召回率、内存、耗时；独立新 run |
| 搜索 · ANN | 28 是精确检索与粗簇索引 | 单独命名的 HNSW 或 FAISS 实验 | 以精确检索核对；同条件召回 / 时延 / 内存曲线；明确测试或排除增量和删除 |
| 搜索 · 查询推荐 | 45 使用构造会话 | 许可清楚的真实查询 / 会话建议实验 | 分清前缀与相关查询；时间切分；热门基线；数据来源与隐私边界 |
| 广告 · 转化和延迟 | 56 使用构造转化与删失 | 真实转化 / 延迟数据与明确观察窗口 | 曝光、点击、转化分母；延迟标签；选择偏差；不把点击伪装成真实转化 |
| 广告 · 归因和增量 | 59 展示记账及已知随机分配 | 数据条件足以支持所用估计量的研究 | 区分归因与因果提升；说明分配 / propensity 假设；反证或敏感性分析 |
| 广告 · 投放系统 | 52 / 62 为请求反馈和单进程账本 | 有边界的 OpenRTB 适配或事务账本 | 协议样例、重复 / 重试、预算不变量和失败测试；不声称生产 RTB 认证 |
| 广告 · 控制 | 58 使用积分式误差反馈 | 有文献依据的控制器或优化方法对照 | 同市场 / 种子；花费约束；价值与消耗权衡；漂移和稀疏流量失败例 |
| 推荐 · 方法深度 | 03–10 含机制练习；11–15 是 XMRec 部分核心方法 | 为一个机制主题补范围明确的真实数据实验 | 方法与声明一致；控制容量 / 训练预算；保持切分；说明与完整论文的差异 |
| 共用 · 可移植性 | 完整流程在 Apple Silicon Mac 验证 | 先验证 Linux，再形成 Windows 路径 | 干净环境日志；依赖要求；免数据阅读检查；一个真实数据实验；不支持项 |

## 小而有用的贡献

| 贡献 | 好的 PR 应包含 |
|---|---|
| 讲清一个单元格 | 学习者的困惑、中英解释、对应输入输出 |
| 修正来源对应 | 作者原链接、尽可能固定版本、准确章节 / 主题 / 页码，区分参考和复现 |
| 修正翻译 | 原句、修改后的英文、上下文术语核对 |
| 加一个反例 | 能暴露错误假设的短确定性样例和有意义的断言 |
| 报告平台问题 | 系统 / 架构、执行命令、脱敏错误、最小复现 |
| 改善可访问性 | 能复现的键盘、对比度或窄屏问题，以及修复验证 |

可通过 [issue 模板](https://github.com/lynnlee1229/search-recommendation-ads-lab/issues/new/choose)描述具体学习问题。资料权利与来源归属是验收的一部分，见[第三方说明](THIRD_PARTY.md)。

## 保持的原则

课程结构由知识体系决定，新增工具归所属领域，共用方法归基础。真实日志、构造样例和模拟市场分开说明。教学训练不悄悄替换正式模型；失败和负结果不会被改写成提升。
